# Master Prompt Generator 🚀

An advanced, native Android AI Prompt Architecture Studio written in **Kotlin**.  
Inspired by **SUN LEY CODER**'s AI App Development workflow, this application bridges the gap between rough app/game ideas and complete, production-grade source code generated by AI models like Claude 3.5 Sonnet, ChatGPT-4o, Google Gemini, and Cursor AI.

---

## 🌟 Key Features

### 1. 🎯 Interactive Conversational Wizard
- **Idea Ingestion**: Enter any app or game idea in plain English or Hindi.
- **Technology Stack Selector**:
  - Flutter (Dart)
  - Kotlin Android (Jetpack Compose & XML Views)
  - React Native (Expo / TypeScript)
  - HTML / CSS / JavaScript (Self-Contained Single File)
  - Next.js / React (TypeScript + Tailwind)
  - Python (FastAPI + Streamlit UI)
  - Java Android
  - Node.js (Express + TypeScript)
  - Swift (SwiftUI)
- **Feature Matrix (Multi-Select)**:
  - 🔐 Authentication (Email/Password, OAuth, OTP)
  - 🛡️ Admin Panel & Management Dashboard
  - 💳 Payment Gateway (Razorpay / Stripe)
  - 🔔 Push Notifications (FCM)
  - 🌓 OLED Dark / Light Mode
  - 🤖 AI / Machine Learning Features
  - 📁 File & Media Upload
  - 💾 Offline Local Database (Room / SQLite / Hive)
  - 🌐 Multi-Language Localization (i18n)
  - 📊 Analytics & Reporting
  - ⚡ Live WebSockets & Realtime Updates
  - 💬 Live Chat Screen
  - 🏆 Tournament Brackets & Fixtures (Single/Double elimination & ELO leaderboards)
  - 👤 User Profile & Settings
  - 🔍 Full-Text Search & Multi-Filters
  - 🔗 Social Deep Linking & Invites
  - 📡 REST API & Webhook Services

### 2. 🧠 Dual Generation Engine
- **Built-in Offline Master Engine**: Works 100% offline without needing any internet connection or API keys! Generates exhaustive, production-grade architectural prompts with complete directory trees, file structures, manifests, and zero-placeholder directives.
- **Cloud AI Engine**: Seamless integration with **Groq Console** (Llama 3.3 70B), **Google Gemini** (Gemini 1.5 Flash/Pro), **OpenAI** (GPT-4o), and **OpenRouter**.

### 3. 📋 Production-Ready Developer Tools
- **1-Tap Markdown Copy**: Fast copy with subtle haptic feedback.
- **Native Share Sheet**: Instantly send prompts to WhatsApp, Telegram, Gmail, or Notes.
- **Direct AI Tester**: Test the generated prompt directly with Groq or Gemini inside the app to watch code generation in real time.
- **Offline History & Starred Vault**: Search, filter, and export prompts directly to your Android device storage.

## 🛠️ Build & Installation

### Requirements
- Android SDK 24+ (Android 7.0 Nougat to Android 15+)
- JDK 17
- Gradle 8.5+

### Build via Gradle
```bash
./gradlew assembleDebug
```
The output APK will be available in:
`app/build/outputs/apk/debug/app-debug.apk`
